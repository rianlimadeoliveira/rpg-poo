# Finalizacao da implementacao RPG

Pacote de implementacao complementar para o repositorio `rianlimadeoliveira/rpg-poo`.

## Como aplicar
1. Abra o projeto Maven no NetBeans ou IntelliJ.
2. Copie a pasta `src` deste pacote para a raiz do projeto, mantendo os caminhos e substituindo os arquivos correspondentes.
3. Execute `mvn test` ou `mvn package`.

## O que foi implementado
- Excecoes de dominio.
- Itens, armas, pocoes e inventario com capacidade fixa.
- Habilidades Bola de Fogo e Cura Rapida.
- Batalha por turnos e servico de batalha com recompensa de XP.
- Repositorio em memoria para herois.
- Metodos de recuperacao de vida e aumento de ataque.
